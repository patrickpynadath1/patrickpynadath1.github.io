This is a sample post to verify the blog pipeline. Create a new file under `src/content/blog/` with frontmatter matching the schema (`title`, `description`, `pubDate`, `author`, `tags`, `heroImage`, `draft`) and Astro will generate the page automatically.

- Write in Markdown (or add MDX later if needed).
- Add `draft: true` to hide posts from the index.
- Assets in `public/` can be referenced directly (e.g., `/images/...`).
